# geo-site · 검색엔진과 AI가 읽는 사이트 짓기⁠​‌‌​​‌‌​​​‌‌​​‌​​​‌‌​​​​​‌‌​​‌‌​​‌‌​​​‌​​​‌‌​‌​​​​‌‌‌​​​​‌‌​​​‌​​​‌‌​​‌​​​‌‌​‌​​​​‌‌​​‌​​​‌‌​​‌‌⁠

내 한 줄로 사이트를 설계하고, 짓고, 올린 뒤 점검해요.

검색엔진과 AI가 읽기 좋은 기본기를 처음부터 넣어 드려요.

<br>

## AI가 나를 소개하려면, 먼저 읽을 수 있어야 해요

글이 그림으로만 있거나, 로봇을 막아 두거나, 페이지마다 제목이 같으면  
검색엔진과 AI는 내 사이트를 제대로 읽지 못해요.

- 객관식으로 페이지 · 메뉴 · 디자인을 정하면 **바로 지어서 내 컴퓨터에서 열어 줘요**
- 기본기를 **자동으로** 넣어요 · 제목 · 설명 · 대표 주소 · 사이트맵 · 로봇 파일 · 구조화 데이터 · 파비콘
- **실제 주소로** 점검해요 · 파일만 보고 통과시키지 않아요

| 이렇게 되어 있으면 | 이렇게 바꿔요 |
|---|---|
| 핵심 문구가 이미지 안에 있어요 | 글자로 넣어요 |
| 모든 페이지 제목이 같아요 | 페이지마다 다르게, 30자 안으로 |
| AI 봇을 막아 두었어요 | 막지 않아요 |
| 사이트맵이 없어요 | 공개 주소만 담은 사이트맵을 만들어요 |

> 기본기는 「읽을 수 있게」 하는 일이에요. 검색 순위나 AI 인용을 보장하지는 않아요.

<br>

## 이 스킬로 얻는 것

- **보면서 고치는 1차 사이트**  
  내 컴퓨터에서 먼저 열어 보고, 「첫 문장 바꿔 줘」처럼 말하면 바로 고쳐요. 올릴지는 마지막에 정해요
- **기본기가 들어간 사이트**  
  제목 · 설명 · 대표 주소 · 사이트맵 · 로봇 파일 · 구조화 데이터 · 파비콘을 넣어 지어요
- **분위기에 맞는 디자인**  
  분위기 · 색 · 글꼴을 고르면 첫 화면 미리보기부터 보여 줘요
- **사이트 리포트 한 장**  
  페이지마다 검색 결과 미리보기 · 채울 것 · 14가지 점검 · 올리는 법을 한 장에 담아요

## 이런 분께

내 사이트를 새로 열고 싶은 분, 만들고 있는 사이트의 기본기를 챙기고 싶은 분,  
이미 운영 중인 사이트가 잘 읽히는지 점검하고 싶은 분.

네이버 블로그 · 티스토리 같은 블로그 플랫폼은 대상이 아니에요.

<br>

## 준비물

- Node.js 18 이상 (Claude Code로 지을 때)
- GitHub · Vercel 무료 계정 (올릴 때 · 직접 가입해요)
- 도메인 (선택 · 무료 주소로 시작해도 돼요)

```
git clone https://github.com/iny101400-young/geo-site ~/.claude/skills/geo-site

```

## 시작

Claude Code에서 이렇게 치세요. (또는 `/geo-site`)

```
사이트 설계해 줘
```

| 이럴 때 | 이렇게 말해요 |
|---|---|
| 올린 사이트를 점검할 때 | `내 사이트 점검해 줘` |
| 점검에서 걸린 걸 고칠 때 | `고쳐 줘` |
| 페이지를 더할 때 | `페이지 추가해 줘` |

<br>

## 이렇게 진행돼요

설계 15분 · 짓기 30~60분 · 점검 10분이에요.

1. 사이트 상황 · 주소 · 만드는 방법을 골라요
2. 페이지와 메뉴, 주소 모양을 정해요
3. 분위기 · 색 · 글꼴을 골라요
4. 바로 지어서 내 컴퓨터에서 열고, 사이트 리포트를 보여 줘요
5. 보면서 고쳐요 · 몇 번이든 돼요
6. 올릴지 정해요 · 올리면 진짜 주소로 다시 점검해요

## 결과물

| 리포트 | 들어 있는 것 |
|---|---|
| 사이트 리포트 | 지금 할 일 · 페이지별 검색 결과 미리보기 · 채울 것 · 14가지 점검과 고치는 법 · 올리는 법 |

파일은 `geo/` 와 `site/` 에 남아요.

| 파일 | 쓰임 |
|---|---|
| `site/` | 지은 사이트 코드 |
| `geo/site-plan.md` | 페이지 · 메뉴 · 주소를 글로 정리한 것 |
| `geo/design.md` | 분위기 · 색 · 글꼴 · 화면 틀 |
| `geo/site-check.json` | 점검 결과 · 검색엔진 등록 전에 다시 써요 |

<br>

## 컨셉을 먼저 정했다면

`컨셉 잡아 줘`(geo-concept)로 만든 `geo/site-copy.json` 이 있으면  
사이트 제목 · 설명 · 첫 화면 문장 · 소개 페이지를 **그대로 가져와요.** 다시 묻지 않아요.

<br>

## 이미 사이트가 있다면

새로 짓지 않고 **실제 주소부터 점검**해요.  
걸린 것 중 고칠 것 세 개를 골라요. 직접 만든 사이트면 고쳐 드려요.

빌더(아임웹 · 카페24 등)로 만든 사이트도 점검은 돼요. 고칠 칸은 빌더 관리 화면에서 직접 바꿔요.

<br>

## 이 스킬로 안 되는 것

- 계정 가입 · 로그인 · 도메인 결제 · 배포 버튼은 직접 해요
- 기본 틀까지만 지어요. 그 뒤 꾸미기와 수정은 자유예요
- 분석 태그(GA4 · Clarity)는 넣지 않아요. 사이트를 연 뒤에 따로 심어요
- 검색 순위나 AI 인용을 보장하지 않아요

## 꼭 알아 둘 것

- **주소는 한 번 정하면 바꾸지 않아요.** 바꾸면 검색에 쌓인 게 처음부터예요
- **점검과 등록은 진짜 주소로 해요.** 미리보기 주소에는 「검색 금지」가 붙어 있어요
- **AI 봇을 막지 않아요.** Cloudflare 같은 곳을 앞에 두었다면 차단 스위치를 꼭 확인해요
- 핵심 문구는 이미지 말고 글자로, 페이지마다 제목은 다르게 써요
- 큰 수정을 한 뒤에는 `내 사이트 점검해 줘` 로 다시 재요
