# 대본 (그대로 쓴다)

업종에 맞는 예시만 바꾼다. `[ ]` 는 AskUserQuestion 의 header.

## 0 · 첫 인사
```
사이트 설계를 시작할게요. (설계 15분 · 짓기 30~60분 · 점검 10분)

AI 가 나를 소개하려면 먼저 내 사이트를 읽을 수 있어야 해요.
글이 그림으로만 있거나, 로봇을 막아 두거나, 페이지마다 제목이 같으면
검색엔진과 AI 가 나를 제대로 못 읽어요.
그래서 컨셉에서 정한 한 줄로, 읽히는 사이트의 기본 틀을 지을게요.

이렇게 진행돼요
1. 사이트 상황 · 주소 · 만드는 방법을 골라요
2. 페이지와 메뉴를 정해요
3. 분위기 · 색 · 글꼴을 골라요
4. 지은 사이트를 내 컴퓨터에서 열어 보고 고쳐요
5. 다 되면 올릴지 정해요 (올리면 진짜 주소로 다시 점검해요)

계정 만들기 · 로그인 · 결제 · 배포 버튼은 직접 해요. 나머지는 제가 해요.
없는 사실이나 숫자는 쓰지 않아요. 말해 주신 것만 써요.
```

## 1 · Q1 · Q2 · Q3 (한 번에)

**Q1 [지금]** 사이트는 지금 어떤 상태예요?
| 선택지 | 설명 |
|---|---|
| 아직 없어요 | 새로 지어요 |
| 만드는 중이에요 | 지금 만든 것을 먼저 봐요 |
| 운영 중이에요 · 고치고 싶어요 | 실제 주소부터 점검해요 |

**Q2 [주소]** 주소는요? (설명: 주소는 한 번 정하면 바꾸기 어려워요. 바꾸면 검색에 쌓인 게 처음부터예요.)
| 선택지 | 설명 |
|---|---|
| 일단 무료 주소로 | 예: 내이름.vercel.app · 나중에 도메인을 붙일 수 있어요 |
| 도메인이 있어요 | 예: mysite.com · 다음에 채팅으로 받아요 |
| 살 예정이에요 | 오래 쓸 거면 지금 사는 걸 권해요 · 사는 법은 올릴 때 알려 드려요 |

- 「무료 주소로」면 이어서 채팅: 「주소 앞부분으로 쓸 영문 이름을 정해 주세요 (예: gyeol-wood → gyeol-wood.vercel.app). 영문 소문자와 하이픈만 돼요. 이미 누가 쓰고 있으면 올릴 때 바꿀 수 있어요.」

**Q3 [방법]** 어떻게 만들까요?
| 선택지 | 설명 |
|---|---|
| Claude Code 로 새로 짓기 (추천) | 제가 코드를 짓고, 올리는 건 Vercel 무료로 안내해요 |
| 빌더로 만들었어요 · 만들 거예요 | 아임웹 · 카페24 등 · 이 스킬은 점검만 해요. 넣을 문구는 컨셉 리포트에서 칸마다 복사해요 |
| 이미 있는 사이트 고치기 | 실제 주소를 먼저 점검하고 고칠 것을 골라요 |

Node.js 가 없을 때(짓기를 골랐는데 `node -v` 가 안 됨):
```
사이트를 지으려면 Node.js 가 필요해요. (무료 · 5분)
· 맥: nodejs.org 에서 「LTS」 설치 파일을 받아 열어요
· 윈도우: nodejs.org 에서 「LTS」 .msi 를 받아 열어요
다 깔았으면 Claude Code 를 껐다 켜고 「계속해 줘」라고 해 주세요.
```

## 2 · Q4 [페이지] (여러 개)
「어떤 페이지가 있으면 좋을까요? 추천을 먼저 골라 뒀어요. 처음엔 4~5개면 충분해요. 주소를 무작정 늘리면 오히려 안 좋아요.」
선택지는 pages.md 의 추천 묶음에서 4개까지(홈은 항상 있어서 빼고). 다섯 번째부터는 「직접 입력」으로 받는다.

## 3 · Q5 [확인]
표를 채팅에 먼저 출력한 뒤: 「페이지마다 이렇게 갈까요?」
이대로 좋아요 / 고칠 게 있어요 / 다시 짜 주세요

사실을 물을 때(한 번에 하나):
- 「(페이지) 첫 화면에 쓸 사실이 하나 더 있으면 좋겠어요. (질문) 모르시면 「나중에」라고 해 주세요. 빈칸은 사이트에 안 나가요.」

## 4 · Q6 [확인]
메뉴 · 주소 표를 채팅에 먼저 출력한 뒤: 「메뉴와 주소는 이렇게 갈까요? 주소는 한 번 정하면 바꾸지 않아요.」
이대로 좋아요 / 메뉴 이름을 바꿀래요 / 주소를 바꿀래요

## 8 · Q10 [다음]
「내 컴퓨터에서 사이트와 리포트를 열었어요. 아직 나만 볼 수 있어요. 어떻게 할까요?」
| 선택지 | 설명 |
|---|---|
| 더 고칠래요 | 바꿀 것을 채팅으로 말해 주세요 (예: 첫 문장 바꿔 줘 · 색 더 밝게) |
| 이대로 올릴래요 | 올리는 법을 알려 드려요 (10분 · 직접 해요) |
| 나중에 올릴래요 | 여기까지 해요. 리포트에 올리는 법이 있어요 |

고친 뒤: 「바꿨어요. 사이트 창을 새로고침해 보세요.」 → 다시 Q10.
