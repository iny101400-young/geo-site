# 페이지 짜기

## 추천 묶음 (Q4)
| 페이지 | id · 주소 | 하는 일 | 추천할 때 |
|---|---|---|---|
| 홈 | home · / | 한 줄 · 하는 일 · 다음 행동 | 항상 |
| 소개 | about · /about | 누구 · 왜 · 근거 (소개문 길게) | 항상 추천 |
| 하는 일 · 상품 · 서비스 | 업종 말로 · 예: /custom · /classes · /services · /booking | 무엇을 · 과정 · 가격 기준 | 항상 추천 |
| 글 모음 | blog · /blog | 3주부터 쓸 글이 모이는 곳 | 항상 추천 (글이 0편이면 사이트맵에서 빠짐) |
| 문의 · 예약 | contact · /contact | 바라는 행동 | 행동이 문의 · 예약 · 구매일 때 |
| 자주 묻는 질문 | faq · /faq | 컨셉의 손님 질문 · 답 | 답을 3개 이상 받았을 때만 |
| 사례 · 작업 | work · /work | 해 본 것 | 사진 · 사례가 이미 있을 때만 (없으면 「채울 것」에) |
| 진료 · 수업 안내 | 업종 말로 | 시간 · 위치 · 과정 | 가게 · 병원 · 학원 |

- 메뉴 이름은 사용자 말로(예: 「작업」 대신 「만든 가구」). id 는 영문.
- 자주 묻는 질문 답이 적으면 따로 페이지를 만들지 않고 「하는 일」 페이지 아래 faq 칸으로 둔다.

## 페이지마다 정할 것 (3단계 표)
| 칸 | 기준 |
|---|---|
| 누가 보나 (who) | 컨셉 대상에서 · 이 페이지에 오는 사람 |
| 검색하는 말 (keyword) | 이 페이지가 받을 말 하나 · 페이지끼리 겹치지 않게 |
| 첫 화면 답 (h1) | 그 말에 대한 답을 한 문장으로. 홈은 컨셉 한 줄을 화면용으로 줄인 것 |
| lead | h1 아래 한두 문장 · 사실만 |
| 다음 행동 (next · cta) | 버튼 하나 · 실제 링크 |
| 제목 (title) | 30자 안 · 「그 페이지가 답하는 한 구절 \| 이름」 · 홈은 site-copy 그대로 |
| 설명 (description) | 80자 안 · 첫 문장에 답 · 홈은 site-copy 그대로 |

## 본문 칸 (sections) — build.mjs 가 그리는 것
| type | 모양 | 칸 |
|---|---|---|
| text | 문단 | heading · body (빈 줄로 문단 나눔) |
| list | 점 목록 | heading · items[] |
| steps | 번호 목록 (과정) | heading · items[] |
| cards | 카드 3~4개 | heading · items[{title, body}] |
| faq | 질문 · 답 (질문은 작은 제목) | heading · items[{q, a}] |
| info | 이름 · 값 (연락처 · 시간 · 위치) | heading · items[{k, v, href?}] |
| cta | 버튼 | label · href |
| todo | **사이트에 안 나감** · 리포트 「채울 것」 | note |

- **사실만.** 칸에 넣는 문장은 site-copy.json · concept.json(「쓸 수 있음」 근거) · 채팅에서 받은 말로만 쓴다. 꾸밈말을 덧붙이지 않는다.
- 가격 · 시간 · 주소 · 전화 · 기간을 모르면 묻고, 「나중에」면 todo.
- faq 의 질문은 concept.json `coreQuestions` 에서, 답은 사용자가 준 것만.
- 홈 첫 칸은 cards(이렇게 해요 · 다른 점 3개)가 잘 맞는다. 소개 페이지 첫 문단은 introLong.
- 규제 업종: 효과 · 전후 · 후기 칸을 만들지 않는다. 시간 · 위치 · 과정 · 자격(사실)만.

## 주소 규칙
- 영문 소문자 + 하이픈 · 날짜 없음 · 끝에 / 없음 (예: /custom, /blog/oil-finish-care)
- 한 번 정하면 바꾸지 않는다. 바꾸면 검색에 쌓인 게 처음부터
- 글 주소는 /blog/영문-이름 · 파일 이름이 주소

## 누구인지 표시 (schemaType)
| 경우 | 값 |
|---|---|
| 개인 | Person |
| 브랜드 · 회사 · 온라인 가게 | Organization |
| 손님이 찾아오는 가게 · 공방 · 학원 (주소를 공개할 때) | LocalBusiness |
| 병원 · 의원 (주소 공개) | MedicalClinic |
주소를 공개하지 않으면 Organization. `contact.address` 가 있을 때만 주소가 들어간다.
